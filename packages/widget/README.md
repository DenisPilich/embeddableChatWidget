# ecw-widget

Встраиваемый чат-виджет. Владелец сайта добавляет одну строку — на странице появляется окно чата, в котором отвечает ассистент.

## Встраивание

```html
<script
  src="https://cdn.jsdelivr.net/npm/ecw-widget@0.1.0/dist/ecw-loader.iife.js"
  data-site-id="site_123"
  async
></script>
```

`data-site-id` выдаётся в дашборде при добавлении сайта.

**Версия в ссылке обязательна.** Без неё следующее обновление пакета молча изменит виджет на всех сайтах, куда он уже встроен. Новая версия — новая ссылка.

## Как это работает

Подключается не сам виджет, а загрузчик:

| Файл | Размер (gzip) | Когда загружается |
|---|---|---|
| `dist/ecw-loader.iife.js` | 592 Б | сразу — это и есть вставка на страницу |
| `dist/ecw-widget.iife.js` | 7.5 КБ | после события `load`, в момент простоя браузера |

Загрузчик ждёт, пока страница клиента загрузится, и только потом подтягивает основной файл. Виджет не должен участвовать в метриках загрузки чужой страницы: по ним клиента ранжирует поиск. Если страница грузится бесконечно, срабатывает страховочный таймаут 3.5 секунды.

Адрес основного файла загрузчик берёт рядом с собой — поэтому версия в ссылке одна на оба файла, и разъехаться они не могут.

## Изоляция от страницы клиента

- Разметка и стили живут в Shadow DOM: стили страницы внутрь не проникают, наши наружу не выходят. Проверено на странице с `!important` на все свойства.
- Наследуемые свойства сбрасываются на внутренней обёртке — селекторы страницы до неё не достают.
- Стили внедряются таблицей стилей из скрипта, поэтому переживают строгую Content Security Policy (проверено на `style-src 'self'` без `unsafe-inline`).
- Host-элемент нулевого размера и не влияет на вёрстку страницы. Если у `<body>` есть `transform`, он переносится в `<html>` — иначе `position: fixed` перестаёт привязываться к окну.
- Весь код обёрнут в защиту от исключений: ошибка виджета не должна ломать чужую страницу.

## Публичный интерфейс на странице

```js
window.ECW.version;            // версия пакета
window.ECW.init({ siteId });   // если параметры не указаны в теге скрипта
window.ECW.open();
window.ECW.close();
window.ECW.toggle();
window.ECW.isOpen();

window.ECW_DEBUG = true;       // включает отладочные сообщения в консоли
```

Повторные вызовы `init` безопасны: второй виджет не появится. Это важно, потому что интеграторы регулярно помещают инициализацию в перемонтируемый компонент.

## Состояние проекта

Версия 0.1.0 — это виджет с демонстрационным ассистентом: он отвечает заготовками, чтобы был виден весь цикл «сообщение → индикатор набора → ответ». Настоящий AI и панель оператора — в следующих версиях. Разработка ведётся открыто, журнал архитектурных решений и план лежат в репозитории.
