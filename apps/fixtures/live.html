Coffee shop page, connected to the real backend

Unlike the other stands, this page talks to the server on localhost:3000 — the one with the database, the model and the operator dashboard. Nothing here goes to the test double.

Ask the assistant something, then press “Talk to a human” in the chat window and open the dashboard. The conversation should be waiting in the queue, and answering there should reach this window.

Needs both running: pnpm dev for this page and pnpm --filter @ecw/web dev for the backend.
